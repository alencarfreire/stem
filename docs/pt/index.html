Documentação

StemPHP é um micro-framework de roteamento em árvore executável, inspirado no Roda. O closure de rotas roda a cada request. Os matchers consomem segmentos da URI conforme avançam. Não há tabela de rotas compilada nem stack de middleware no core.

  • PHP-FPM
  • php -S
  • FrankenPHP
  • RoadRunner
  • Swoole

Instalar

BASH
composer require alencarfreire/stem

Exige PHP 8.3+. FrankenPHP, RoadRunner e Swoole são opcionais. O require do core é só php.

Início rápido

Front controller para PHP-FPM ou php -S:

PHP
use Stem\App;
use Stem\Request;

$app = new App();

$app->route(function (Request $r): void {
    $r->root(fn () => $r->json(['message' => 'StemPHP API']));

    $r->on('users', function () use ($r): void {
        $r->get(fn () => $r->json([['id' => 1, 'name' => 'John']]));
        $r->post(fn () => $r->json(['id' => 2], 201));

        $r->onInt(function (int $id) use ($r): void {
            $r->get(fn () => $r->json(['id' => $id, 'name' => 'John']));
            $r->delete(fn () => $r->halt(204));
        });
    });
});

$app->run();
BASH
php -S localhost:8080 examples/basic/index.php

Como o matching funciona

O Roda não compila rotas numa trie no boot. O StemPHP faz o mesmo: o App guarda um closure. O handle() executa. Cada matcher é um if que pode consumir o próximo segmento.

GET /users/7
restante /users/7
on('users') consome users → /7
get() atEnd? não — pula
onInt() captura 7 → vazio
get() folha terminal → json
  • Um matcher que casa roda o callback e marca $done. Irmãos naquele nível não rodam.
  • Se nada na árvore inteira casar, handle() devolve 404.
  • Se um ramo casar (on/onInt) mas nenhuma folha escrever body, você leva 200 vazio — o ramo já consumiu o path. Não há backtracking.

Matchers

ChamadaSignificado
$r->on('users', $cb)Prefixo. Consome users e entra no ramo.
$r->is('users', $cb)Path restante exato /users.
$r->is($cb)Path restante vazio.
$r->get($cb) / post / put / delete / patchMétodo HTTP e path restante vazio (terminal).
$r->get('about', $cb)Método + restante exato /about.
$r->root($cb)Restante é / ou vazio. Qualquer método.
$r->onInt($cb)Próximo segmento é inteiro: 0, 42. Não 01, -1, overflow.
$r->onParam($cb)Próximo segmento não vazio, como string.
$r->json($data, $status = 200)Body JSON + content type. Marca $done. Não lança.
$r->html($html, $status = 200)Body HTML. Marca $done. Não lança.
$r->halt($status, $body, $headers)Saída antecipada (never). Lança HaltException interna.

Desvio do Roda: get() / post() sem segmento são terminais (método + restante vazio). O r.get nu do Roda casa GET mesmo com path sobrando — fácil engolir /users/1/posts. Coloque ramos on() aninhados acima da folha get().

Callbacks e $r

Matchers não injetam Request como argumento. Isso tira Reflection do caminho quente. Capture $r do closure de route() com use ($r) ou arrows:

PHP
$r->on('users', function () use ($r): void {
    $r->onInt(fn (int $id) => $r->json(['id' => $id]));
});

Só onInt / onParam passam argumentos extra (a captura). function (Request $r) como parâmetro de matcher dá erro.

Playground de path

A mesma árvore do início rápido. Clique numa request e veja consume / miss / folha.


        

      


      

        
Request

        
Request é a mensagem HTTP e o contexto de roteamento ($r).

        

          
            
MétodoPapel

          
          
            
Request::fromGlobals()Handler FPM / worker. Chame dentro do loop por request.

            
Request::create($method, $path, $headers, $query, $body)Testes, RoadRunner, Swoole.

            
method() / path() / remaining()Verbo, path normalizado, sufixo não consumido.

            
header($name) / headers()Lazy: $_SERVER só é varrido no primeiro acesso.

            
query() / rawBody()Query string e body cru. GET/HEAD não leem php://input.

            
response()Aloca Response na primeira escrita.

          
        

        
Paths são normalizados: barra final removida (exceto /), // colapsado, query/fragment descartados, percent-decode por segmento.

      


      

        
Response

        
Mutável e com escopo da request. json() / html() no Request escrevem aqui e marcam $done.

        

          
            
MétodoPapel

          
          
            
status() / headers() / body()Lê a mensagem atual.

            
withStatus / withHeader / withBodyMutators fluentes. CR/LF em headers é rejeitado.

            
writeJson / writeHtmlBody + content type. JSON usa JSON_THROW_ON_ERROR.

            
send()http_response_code, headers, echo. Idempotente.

          
        

      


      

        
Ciclo do App

        

          
PHP

          
$app->route(function (Request $r): void { /* uma vez */ });
$response = $app->handle($request);   // por request
$app->run();                          // fromGlobals + handle + send

        

        
    
          
  • route() só pode ser chamado uma vez. A segunda chamada lança LogicException.
    • 
          
  • handle() captura só HaltException. Outros throwables sobem para o SAPI.
    • 
          
  • O happy path (json/html) não lança.
    • 
        

      


      

        
Runtimes

        

          

            
PHP-FPM / php -S

            
Padrão. Aponte o document root para um script que chama $app->run(). Veja examples/basic/index.php.

          

          

            
FrankenPHP worker

            
Opcional. Suba o $app uma vez, depois FrankenPhpWorker::run($app). O fromGlobals() fica dentro do loop.

          

          

            
RoadRunner

            
Sem require no Composer. Mapeie o request PSR-7 para Request::create e grave status/headers/body. Veja examples/roadrunner/.

          

          

            
Swoole

            
O mesmo contrato: handle() é o kernel. Exemplo em examples/swoole/server.php.

          

        

        

          
PHP

          
use Stem\Integrations\FrankenPhpWorker;

FrankenPhpWorker::run(
    $app,
    maxRequests: (int) ($_SERVER['MAX_REQUESTS'] ?? 0),
    collectEvery: 0, // gc_collect_cycles off; use 128 se alguma extensão vazar
);

        

      


      

        
Isolamento

        
Workers long-lived reutilizam a instância de App. Não podem reutilizar um Request.

        
    
          
  • Nenhum estado estático de request em App, Request, Response ou Router.
    • 
          
  • handle() sempre recebe um Request novo.
    • 
          
  • Response nasce na primeira escrita e não é compartilhado entre requests.
    • 
          
  • Request::fromGlobals() fica no handler, nunca no boot do worker.
    • 
        

      


      

        
Performance

        
O custo de roteamento é O(profundidade do path × irmãos naquele nível), não O(total de rotas). É o modelo do Roda, não o matcher compilado do FastRoute.

        
    
          
  • Sem regex, sem Reflection, sem exception em json() / html().
    • 
          
  • Parse do path usa strpos / explode. rawurldecode só se a URI tiver %.
    • 
          
  • onInt usa ctype_digit + (int).
    • 
          
  • GET/HEAD não leem php://input. Headers de $_SERVER são lazy.
    • 
        

        
Meça no seu hardware. Não publique req/s inventado:
