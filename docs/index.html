Documentation

StemPHP is an executable routing-tree micro-framework inspired by Roda. The route closure runs on every request. Matchers consume URI segments as they go. There is no compiled route table and no middleware stack in the core.

  • PHP-FPM
  • php -S
  • FrankenPHP
  • RoadRunner
  • Swoole

Install

BASH
composer require alencarfreire/stem

Requires PHP 8.3+. FrankenPHP, RoadRunner and Swoole are optional. The core require is only php.

Quick start

Create index.php in your project root (next to vendor/):

PHP
require __DIR__ . '/vendor/autoload.php';

use Stem\App;
use Stem\Request;

$app = new App();

$app->route(function (Request $r): void {
    $r->root(fn () => $r->json(['message' => 'StemPHP API']));

    $r->on('users', function () use ($r): void {
        $r->get(fn () => $r->json([['id' => 1, 'name' => 'John']]));
        $r->post(fn () => $r->json(['id' => 2], 201));

        $r->onInt(function (int $id) use ($r): void {
            $r->get(fn () => $r->json(['id' => $id, 'name' => 'John']));
            $r->delete(fn () => $r->halt(204));
        });
    });
});

$app->run();

Start the built-in server with that file as the router (so /users is not looked up as a path on disk):

BASH
php -S localhost:8080 index.php

How matching works

Roda does not compile routes into a trie at boot. StemPHP does the same: App stores one closure. handle() runs it. Each matcher is an if that may consume the next segment.

GET /users/7
remaining /users/7
on('users') consume users → /7
get() atEnd? no — skip
onInt() capture 7 → empty
get() terminal leaf → json
  • A matcher that hits runs its callback, then seals that level. Siblings do not run.
  • If nothing in the whole tree hits, handle() returns 404.
  • If a branch hits but no leaf writes a body: leftover path → 404; wrong method → 405 with Allow. There is no backtracking.

Matchers

CallMeaning
$r->on('users', $cb)Prefix. Consumes users, enters the branch.
$r->is('users', $cb)Exact remaining path /users.
$r->is($cb)Remaining path is empty.
$r->get($cb) / post / put / delete / patchHTTP method and remaining path empty (terminal).
$r->get('about', $cb)Method + exact remaining /about.
$r->root($cb)Remaining is / or empty. Any method.
$r->onInt($cb)Next segment is an integer: 0, 42. Not 01, -1, overflow.
$r->onParam($cb)Next non-empty segment as string.
$r->json($data, $status = 200)JSON body + content type. Sets $done. Does not throw.
$r->html($html, $status = 200)HTML body. Sets $done. Does not throw.
$r->halt($status, $body, $headers)Early exit (never). Throws internal HaltException.
$r->redirect($url, $status = 302)Location + status.
$r->noContent()HTTP 204.
$r->cookie($name, $value, $options = [])Set-Cookie (no CR/LF).
$r->options($cb)Same as other verbs. Bare OPTIONS also gets automatic 204 + Allow when verbs were visited.

Deviation from Roda: get() / post() without a segment are terminal (method + empty remaining). Roda’s bare r.get matches GET even with leftover path — easy to swallow /users/1/posts. Put nested on() branches above the leaf get().

Callbacks and $r

Matchers do not inject Request as an argument. That keeps Reflection off the hot path. Capture $r from the route() closure with use ($r) or arrows:

PHP
$r->on('users', function () use ($r): void {
    $r->onInt(fn (int $id) => $r->json(['id' => $id]));
});

Only onInt / onParam pass extra arguments (the capture). function (Request $r) as a matcher parameter will error.

Request

        
Request is both the HTTP message and the routing context ($r).

        

          
            
MethodRole

          
          
            
Request::fromGlobals()FPM / worker handler. Call inside the per-request loop.

            
Request::create($method, $path, $headers, $query, $body)Tests, RoadRunner, Swoole.

            
method() / path() / remaining()Verb, normalized path, unconsumed suffix.

            
header($name) / headers()Lazy: $_SERVER is scanned only on first access.

            
query() / queryParam($key, $default)Full query array, or one key.

            
form() / formParam($key, $default)$_POST fields from fromGlobals().

            
rawBody() / jsonBody()Raw body. JSON decode; invalid JSON → halt(400). GET/HEAD skip php://input.

            
bearerToken() / wantsJson()Authorization: Bearer and Accept.

            
response()Allocates Response on first write.

          
        

        
Paths are normalized: trailing slash stripped (except /), // collapsed, query/fragment dropped, percent-decoding per segment.

      


      

        
Response

        
Mutable and request-scoped. json() / html() / redirect() / noContent() write here. HEAD matches get(); send() omits the body.

        

          
            
MethodRole

          
          
            
status() / headers() / body()Read the current message.

            
withStatus / withHeader / withBodyFluent mutators. CR/LF in headers is rejected.

            
writeJson / writeHtmlBody + content type. JSON uses JSON_THROW_ON_ERROR.

            
send()http_response_code, headers, echo. Idempotent.

          
        

      


      

        
App lifecycle

        

          
PHP

          
$app->route(function (Request $r): void { /* once */ });
$response = $app->handle($request);   // per request
$app->run();                          // fromGlobals + handle + send

        

        
    
          
  • route() may be called once. A second call throws LogicException.
    • 
          
  • notFound(fn (Request $r) => ...) and error(fn (Throwable $e, Request $r) => ...) are optional.
    • 
          
  • handle() catches HaltException. Other throwables go to error() if set, otherwise bubble.
    • 
          
  • Happy path (json/html) does not throw.
    • 
        

      


      

        
Runtimes

        

          

            
PHP-FPM / php -S

            
Default. Serve the same index.php as the front controller (php -S localhost:8080 index.php, or point PHP-FPM/Apache at that file).

          

          

            
FrankenPHP worker

            
Optional. Boot $app once, then FrankenPhpWorker::run($app). fromGlobals() stays inside the loop.

          

          

            
RoadRunner

            
No Composer require. Map the PSR-7 request to Request::create, then write status/headers/body. See examples/roadrunner/.

          

          

            
Swoole

            
Same contract: handle() is the kernel. Example in examples/swoole/server.php.

          

        

        

          
PHP

          
use Stem\Integrations\FrankenPhpWorker;

FrankenPhpWorker::run(
    $app,
    maxRequests: (int) ($_SERVER['MAX_REQUESTS'] ?? 0),
    collectEvery: 0, // gc_collect_cycles off; set 128 if an extension leaks
);

        

      


      

        
Isolation

        
Long-lived workers reuse the App instance. They must not reuse a Request.

        
    
          
  • No static request state on App, Request, Response, or Router.
    • 
          
  • handle() always receives a new Request.
    • 
          
  • Response is created on first write, not shared across requests.
    • 
          
  • Request::fromGlobals() belongs in the handler, never at worker boot.
    • 
        

      


      

        
Performance

        
Routing cost is O(path depth × siblings at that level), not O(total routes). This is Roda’s model, not FastRoute’s compiled matcher.

        
    
          
  • No regex, no Reflection, no exception on json() / html().
    • 
          
  • Path parse uses strpos / explode. rawurldecode only if the URI contains %.
    • 
          
  • onInt uses ctype_digit + (int).
    • 
          
  • GET/HEAD skip php://input. Headers from $_SERVER are lazy.
    • 
        

        
Measure on your hardware against your own index.php. Do not publish invented req/s:

        

          
BASH

          
php -S 127.0.0.1:8080 index.php
wrk -t4 -c64 -d10s http://127.0.0.1:8080/
